# 牛客专项知识题库

## 在线入口

### [点击进入在线题库](https://icebingk.github.io/nowcoder-quiz/)

手机和电脑都可以直接访问。使用同一个邮箱登录后，答题记录、错题和收藏会保存到云端并跨设备同步。

## 主要功能

- 764 道数字电路、Verilog 和 FPGA/CPLD 专项知识题
- 一题一题作答、左右切题和题号导航
- 做过、未做、错题、收藏及非选择题筛选
- 答案解析与复习资料
- 本地离线保存和 Supabase 云同步

## 迁移原来的本地进度

1. 在原来的本地题库中点击“导出本机进度”。
2. 打开[在线题库](https://icebingk.github.io/nowcoder-quiz/)并登录邮箱。
3. 点击“导入进度”，选择导出的 JSON 文件。
4. 页面显示“已保存到云端”后，即可在其他设备登录同一邮箱继续答题。

题目与答案仅用于个人学习，题面以原网站为准。
